# Video Controller 기능 명세 (테스트 케이스)

이 문서는 확장 프로그램의 기능을 테스트 케이스 단위로 정리한 명세입니다.
`자동` 열이 ✅인 항목은 `pnpm test`로 검증되며, 테스트 이름이 케이스 ID로 시작합니다.
🖐️ 항목은 실제 크롬과 유튜브에서 사람이 확인해야 합니다.

- 팝업 테스트: `tests/popup.test.jsx` (가짜 chrome API + 가짜 content script)
- content script 테스트: `tests/content.test.js` (jsdom 위의 가짜 `<video>`)
- 피치 워클릿 테스트: `tests/worklet.test.js` (오프라인 신호 처리)
- 단축키 백그라운드 테스트: `tests/background.test.js`

## 10. 키보드 단축키 (KEY)

`chrome://extensions/shortcuts`에서 바꿀 수 있습니다. 크롬은 기본 키를 4개까지만 허용해서, 피치와 반복 켜기/끄기는 직접 지정해야 합니다.

| 명령 | 기본 키 | 동작 |
|---|---|---|
| speed-up / speed-down | Alt(⌥)+Shift+. / , | 속도 ±0.1x |
| loop-a | Alt(⌥)+Shift+A | 현재 위치를 A로 |
| loop-b | Alt(⌥)+Shift+B | 현재 위치를 B로 하고 A~B 반복 시작 |
| pitch-up / pitch-down | (직접 지정) | 피치 ±1 반음 |
| loop-toggle | (직접 지정) | 반복 켜기/끄기 |

| ID | 조건 | 동작 | 기대 결과 | 자동 |
