===== 상세 설명 =====

🎵 Video Controller - 유튜브 속도·피치·A-B 반복

느리게 듣고, 키를 바꾸고, 어려운 구간만 반복하세요.
음악 연습, 어학 공부, 강의 시청을 위해 만들었어요.


🆕 v4.4.0 새로워진 점

✅ 속도·피치·반복이 완전히 따로 동작해요. 하나를 바꿔도 나머지 둘은 설정한 그대로예요
✅ 구간 반복이 부드럽게 재생돼요. 반복을 켰을 때 버벅이거나 멈추던 문제를 고쳤어요
✅ 피치를 올려도 지직거리는 잡음이 나지 않아요
✅ "Now" 버튼으로 지금 재생 위치를 A·B 지점으로 바로 지정해요
✅ 키보드 단축키로 팝업을 열지 않고도 속도를 바꾸고 A·B를 지정해요
✅ 팝업이 한 화면에 다 들어와요. 스크롤할 필요가 없어요
✅ 팝업을 열면 바로 연결되고, 다시 열어도 지금 설정이 그대로 보여요
✅ 같은 영상 안에서 앞뒤로 이동해도 설정이 초기화되지 않아요


✨ 주요 기능

🚀 재생 속도
• 0.25배 ~ 4.0배
• −0.2 / −0.1 / +0.1 / +0.2 버튼으로 세밀하게 조절
• 프리셋: 60%, 70%, 80%, 90%, 110%, 120%
• 가운데 현재 속도를 누르면 1.0배로 돌아가요
• 유튜브 플레이어가 속도를 바꿔도 설정한 속도를 유지해요


🎵 음계(피치)
• 반음 단위로 −24 ~ +24 (위아래 2옥타브)
• −2 / −1 / +1 / +2 반음 버튼과 온음 프리셋(−2T, −1T, +1T, +2T)
• 속도는 그대로 두고 키만 바꿔요
• 가운데 현재 피치를 누르면 원래 키로 돌아가요


🔁 A-B 구간 반복
• "Now"를 누르면 지금 위치가 A 또는 B가 돼요 (B를 지정하면 바로 반복 시작)
• 시간 직접 입력("1:30" 또는 "90")이나 슬라이더 드래그로도 지정할 수 있어요
• B까지 끝까지 재생한 뒤 A로 돌아가요
• 자동재생 목록에서도 다음 영상으로 넘어가지 않아요
• 노란 표시로 현재 재생 위치를 보여줘요


⌨️ 키보드 단축키
• 속도 올리기 / 내리기: Alt(⌥) + Shift + . / ,
• A 지점 지정: Alt(⌥) + Shift + A
• B 지점 지정 + 반복 시작: Alt(⌥) + Shift + B
• 피치 올리기·내리기, 반복 켜기·끄기는 chrome://extensions/shortcuts 에서 직접 지정할 수 있어요
• 단축키를 누르면 화면에 짧은 안내가 떠요 (전체화면에서도 보여요)


🎛️ 전체 ON/OFF 스위치
• 모든 기능을 한 번에 끄고 원래 영상 소리를 들을 수 있어요
• 다시 켜면 설정이 돌아와요
• ON/OFF 상태는 기억돼요


🔄 새 영상에서 자동 초기화
• 다른 영상으로 넘어가면 설정이 기본값으로 돌아가요
• 같은 영상 안에서 이동하거나 반복하거나 처음으로 돌아가도 설정은 유지돼요


💡 이럴 때 써 보세요

🎸 음악 연습
• 어려운 구간을 A-B로 반복하면서 속도를 낮춰 연습
• 내 목소리나 악기에 맞게 키 조절

📚 어학 공부
• 한 문장을 다 들릴 때까지 반복
• 빠른 말을 천천히

🎓 강의 시청
• 중요한 설명 부분만 다시 듣기
• 느린 부분은 빠르게


📖 사용 방법

1. 유튜브 영상을 재생해요
2. 확장 프로그램 아이콘을 눌러요
3. 팝업에서 속도·피치·반복을 조절하거나, 키보드 단축키를 써요


⚠️ 참고

• 유튜브에서만 동작해요
• 일부 DRM 보호 콘텐츠는 지원되지 않을 수 있어요
• 피치 조절을 쓰는 동안에는 영상 원래 소리가 음소거되고, 피치를 바꾼 소리가 대신 나와요
• 확장 프로그램을 업데이트한 뒤에는 유튜브 탭을 한 번 새로고침해 주세요


🔒 개인정보 보호

• 저장하는 건 전체 ON/OFF 설정 하나뿐이고, 내 기기에만 저장돼요
• 어디로도 정보를 보내지 않아요
